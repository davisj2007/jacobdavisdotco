How I Think About Analytics

Good analytics answers questions that matter, in language stakeholders understand, with recommendations they can actually implement.

I favor clarity over complexity, practical over theoretical, done over perfect. My goal is to make myself unnecessary — to leave clients with frameworks they can run themselves.

Tools & Methods

I leverage statistical computing software meant for big data and write my own code.

I prefer to use the simplest method that answers the question.

I'm skeptical of analytics theater — complex methods deployed to impress rather than inform. If a cross-tab answers the question, we don't need machine learning, but I am comfortable deploying more sophisticated methods when necessary.

Beyond Work

I run a side project called Jake Davis Analytics, where I apply analytical methods to sports and other non-professional topics. It's my sandbox for trying new techniques and writing for a broader audience.
